## Booking

The three-step enquiry validates dates and the guest name, calculates nights, and generates a URL-encoded WhatsApp message. The visitor sends it in WhatsApp. No automatic booking confirmation, payment collection, database, or availability calendar is represented.

Property inventory, nightly rates, exact addresses, amenities and booking terms have not been supplied; the host confirms these by enquiry. Kyanja location is shown in the supplied promotional footage. Gallery and tour names describe imagery, not verified individual listing names.

## Media

The logo is supplied by the user. All property images are extracted from supplied videos. Four silent, compressed walkthrough clips are selected from those videos; presenter intros and promotional endings are excluded. Originals are untouched. `prepare_media.py` documents the selected source files and timings. `qa/` is local-only verification output.

## Design references

User-supplied hospitality templates inspired the restrained palette, serif headlines and photography-led sections. Additional editorial hospitality inspiration: https://theaficionados.com/. No third-party property photos or testimonials are used.
